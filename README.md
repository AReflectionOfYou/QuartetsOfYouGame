# Quartets of You

An open-source word-grouping puzzle: sort sixteen words into four quartets. Write your own puzzles for weddings, reunions, classrooms, or family nights.

Part of the [A Reflection of You](https://github.com/AReflectionOfYou) collection — tools and games that reflect the people who use them.

## Status

Early development
